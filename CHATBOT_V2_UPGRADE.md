## 💬 Conversational Features

### What You Can Now Ask

#### 1. **Direct Questions About Violations**
```
You: "What about cheating?"
Bot: Returns full recommendation with severity, alternatives, and guidelines
```

#### 2. **Severity Assessment**
```
You: "Is cussing serious?"
Bot: 🔴 SEVERITY ASSESSMENT
     This is a MODERATE violation...
     Provides context for punishment decision
```

#### 3. **Alternative Punishments**
```
You: "What are other options instead of a game ban?"
Bot: Lists alternatives with pros/cons:
     - Tournament Ban (shorter, tests reform)
     - Match Bans (multiple, escalating)
     - Probation + monitoring
```

#### 4. **General Guidelines**
```
You: "Tell me about guidelines"
Bot: Explains:
     1️⃣ First Offense - lighter punishment
     2️⃣ Repeat Offender - escalation rules
     3️⃣ Serious Violations - evidence requirements
     4️⃣ Context Matters - other factors
```

#### 5. **Help & Discover**
```
You: "help"
Bot: Shows all 15+ violations grouped by severity:
     🔴 CRITICAL (Permanent/Long)
     🟠 SERIOUS (Medium-Long)
     🟡 MODERATE (Short-Medium)
```

#### 6. **Casual Greeting**
```
You: "hello"
Bot: Friendly response explaining capabilities
```

## 🔄 Example Conversations

### Conversation 1: Discussing Cheating
```
👨‍💼 You: What about cheating?

🤖 Bot: 🎯 PUNISHMENT RECOMMENDATION
        ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
        Violation: Cheating
        Recommended: Game Ban (Permanent or Extended)
        Duration: 3-12 months
        
        Description: Using unauthorized tools, hacks, exploits...
        
        📝 ADMIN GUIDANCE:
        ⚠️ Consider permanent ban for repeat offenders...

👨‍💼 You: Is this serious?

🤖 Bot: 📊 SEVERITY ASSESSMENT
        ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
        Violation: Cheating
        This is a CRITICAL violation - the most serious category
        ⚠️ Consider permanent ban for repeat offenders...

👨‍💼 You: What are alternatives?

🤖 Bot: 🔄 ALTERNATIVE ACTIONS
        ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
        For: Cheating
        Primary: Game Ban (3-12 months)
        
        Alternatives to consider:
        • Tournament Ban (shorter, tests reform)
        • Match Bans (multiple, escalating)
        • Probation + monitoring
        
        Choose based on:
        • Severity of violation
        • Player history
        • Impact on competition
        • Evidence strength
```

### Conversation 2: Discussing Cussing
```
👨‍💼 You: Tell me about cussing

🤖 Bot: 🎯 PUNISHMENT RECOMMENDATION
        Violation: Cussing/Offensive Language
        Recommended: Match/Tournament Ban (Progressive)
        Duration: 1-7 days (first), 7-30 days (repeat)
        
        Description: Using profanity, slurs, or offensive language...
        
        📝 ADMIN GUIDANCE:
        🟡 First offense: 1-7 day ban. Repeat: escalate to 7-30 days

👨‍💼 You: Guidelines?

🤖 Bot: 📋 PUNISHMENT GUIDELINES
        1️⃣ FIRST OFFENSE
           • Use lower end of suggested duration
           • Consider if it was accidental
        
        2️⃣ REPEAT OFFENDER
           • Escalate to middle range
           • Consider pattern of behavior
        
        3️⃣ SERIOUS/EVIDENCE
           • Use upper end of range
           • Document all evidence
        
        4️⃣ CONTEXT MATTERS
           • Tournament tier level
           • Player impact
           • Team reputation

👨‍💼 You: Alternatives to match ban?

🤖 Bot: 🔄 ALTERNATIVE ACTIONS
        For: Cussing
        Primary: Match/Tournament Ban (1-7 days)
        
        Alternatives:
        • Warnings + monitoring
        • Tournament Ban (if serious)
        • Mandatory training/reform
```
