# Conversational Ban Chatbot - Quick Guide v2.0

**What's Changed**: You can now DISCUSS punishments, not just receive recommendations!

---

## 🎯 What You Can Now Do

### 1️⃣ Ask About Violations
```
You: "What about cheating?"
Bot: Shows full recommendation with severity, description, and admin notes
```

### 2️⃣ Assess Severity
```
You: "Is this serious?"
Bot: Explains if it's CRITICAL, SERIOUS, MODERATE, or MINOR
      Provides context for decision-making
```

### 3️⃣ Explore Alternatives
```
You: "What are other options?"
Bot: Lists alternative punishments with pros/cons
     Shows why each option might work
```

### 4️⃣ Understand Guidelines
```
You: "Tell me guidelines"
Bot: Explains how to handle first offenses, repeat offenders, and context
```

### 5️⃣ Discover All Violations
```
You: "help"
Bot: Lists all violations grouped by severity (CRITICAL → MODERATE)
```

### 6️⃣ Casual Conversation
```
You: "hello"
Bot: Friendly greeting explaining what it can help with
```

## 💬 Example Conversations

### Example 1: Cheating Case
```
👨‍💼 You: What about cheating?

🤖 Bot: 🎯 PUNISHMENT RECOMMENDATION
        Violation: Cheating
        Recommended: Game Ban (Permanent or Extended)
        Duration: 3-12 months
        [Full description and admin notes...]

👨‍💼 You: Is this serious?

🤖 Bot: 📊 SEVERITY ASSESSMENT
        This is a CRITICAL violation
        [Detailed explanation...]

👨‍💼 You: What if it's first offense?

🤖 Bot: For a first-time cheater:
        • Consider 3-6 month ban (lower end)
        • Monitor behavior closely
        • Permanent ban only if repeat or severe
```

### Example 2: Cussing Case
```
👨‍💼 You: Tell me about cussing

🤖 Bot: [Full recommendation with 1-7 day ban for first offense...]

👨‍💼 You: Guidelines?

🤖 Bot: 📋 PUNISHMENT GUIDELINES
        1️⃣ FIRST OFFENSE: 1-7 days
        2️⃣ REPEAT: Escalate to 7-30 days
        3️⃣ SERIOUS: Use upper range
        4️⃣ CONTEXT: Consider player history

👨‍💼 You: Alternatives instead of tournament ban?

🤖 Bot: 🔄 ALTERNATIVE ACTIONS
        • Warning + monitoring (lightest)
        • Match Bans (multiple, escalating)
        • Mandatory training/reform
```

## 🎯 Common Questions

**Q: Why can't the chatbot apply bans automatically?**  
A: Because you should review and make the final decision. The chatbot recommends, you decide.

**Q: Can I talk naturally to it?**  
A: Yes! Ask "Is this serious?" or "What are alternatives?" - it understands.

**Q: Is the text readable now?**  
A: Yes! White text on dark backgrounds with high contrast.

**Q: Can I ask about violations not in the list?**  
A: You can try, but it's most helpful for the 15+ built-in types.

**Q: How do I see all violations?**  
A: Type "help" and it lists all 15+ violations grouped by severity.
