## 🔊 User Experience Flow

```
START
  │
  ├─→ User sees login page
  │   Shows email, password, reCAPTCHA
  │
  ├─→ User clicks checkbox
  │   "I'm not a robot"
  │
  ├─→ System picks random quiz:
  │   ├─ 33% Multiple Choice
  │   ├─ 33% Text Input
  │   └─ 34% Image Grid
  │
  ├─→ Quiz displays
  │   User sees question/challenge
  │
  ├─→ User solves challenge
  │   - Selects answer
  │   - Types answer
  │   - Clicks checkboxes
  │
  ├─→ User clicks "Verify"
  │   System validates...
  │
  ├─→ SPLIT:
  │   │
  │   ├─ CORRECT ✓
  │   │  - Success message
  │   │  - Token generated
  │   │  - Checkbox stays checked
  │   │
  │   └─ WRONG ✗
  │      - Error alert
  │      - Checkbox unchecked
  │      - NEW question offered
  │      - Loop back to retry
  │
  ├─→ (If correct) User enters credentials
  │   Email + Password
  │
  ├─→ User clicks "Sign In"
  │   System verifies credentials
  │
  └─→ END (Login complete or error)
```
